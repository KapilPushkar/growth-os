Architecture

How Growth OS is built

One FastAPI service and one database behind a single React app. Every module keys off the client, so a post, its reach, the lead it produced and the deal it closed can be traced in one place.

Stack

React 19 + TypeScript + Vite, with no router or chart libraries. FastAPI, Pydantic v2 and SQLAlchemy 2.0. JWT auth with PBKDF2 password hashing.

Data model

Client, User, Campaign, Content, ApprovalEvent, Lead, Keyword, GEO check, weekly MetricSnapshot and Activity. Everything is scoped to the client.

Quality

59 backend tests (auth, tenant isolation, workflow, auto-approve, AI fallback), an end-to-end smoke test of this exact story, and CI on every push.

Simulated for now

Publishing to LinkedIn/X, post metrics, rank refresh and GEO for engines without a key. Each is labelled in the app and ready to swap for a real integration.
